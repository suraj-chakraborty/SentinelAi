# SentinelAI Voice Command Reference

This document lists the primary voice commands and trigger phrases supported by SentinelAI.

## 🖥️ System & App Control
| Action | Example Phrases |
| :--- | :--- |
| **Open Application** | "Open Google Chrome", "Launch Notepad", "Run Spotify" |
| **Close Application** | "Close Docker", "Exit Photoshop", "Terminate Calculator" |
| **Lock Computer** | "Lock my PC", "Lock the screen" |
| **Power Management** | "Shutdown computer", "Restart Windows", "Reboot PC" |
| **System Status** | "Show system status", "Check CPU usage", "Battery level" |
